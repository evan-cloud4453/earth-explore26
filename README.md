# 지구탐사 퀴즈

2026학년도 2학기 「지구탐사」 중간고사 대비 퀴즈 사이트. 문제집 4종 283문항을 주제별로 풀 수 있다.

| 문제집 | 문항 | 내용 |
| --- | --- | --- |
| 예상 104제 | 104 | 강의 노트·수업 녹취 중심 예상문제(6주제) |
| 추가 100제 | 100 | 예상 104제·복습 노트·다큐 퀴즈와 겹치지 않는 새 문항(6주제) |
| 고난도 50제 | 50 | 지엽적 출제 대비 — 수업에 나온 세부 수치·연도·인물·사례(6주제) |
| 다큐 퀴즈 기출 | 29 | 실제 출제된 지구대기행 퀴즈를 문장 그대로(6편) |

- **시작하기** → 위쪽 탭에서 문제집을 고른 뒤 주제를 골라 한 문항씩 풀고, 바로 정답·해설·근거(강의 노트 쪽, 녹취 시각)를 본다.
- 문항 유형: 하나 고르기 · 모두 고르기 · O/X · 단답형. 단답형은 띄어쓰기·괄호 속 다른 표현까지 허용해 자동 채점하고, 놓친 표현은 "정답으로 처리"할 수 있다.
- **오답노트(기록보관소)** → 틀린 문항이 문제집·주제별로 쌓인다. 내 답·정답·해설을 다시 보고, 오답만 모아 다시 풀 수 있다. 다시 맞히면 "다시 맞힘"으로 표시된다.
- 기록은 브라우저(localStorage)에만 저장된다. 다른 기기·브라우저와는 공유되지 않는다.

키보드: `1`~`5` 보기 선택, `O`/`X`, `Enter` 다음 문제.
